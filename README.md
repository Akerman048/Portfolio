# React Portfolio Website

A modern and fully responsive portfolio website built with React and Firebase.  
The project features dynamic theme customization, animated live backgrounds powered by Vanta.js, centralized state management with React Context API, and optimized performance for a smooth user experience.

## Features

- Modern responsive portfolio website
- Built with React
- Dynamic theme switching
- Live animated background using Vanta.js
- Centralized state management with Context API
- Firebase integration
- Dynamic content storage and retrieval
- Optimized component rendering
- Reusable component architecture
- Smooth animations and transitions
- Mobile-friendly design
- Clean UI/UX

## Tech Stack

- React
- JavaScript
- CSS / Tailwind CSS
- Firebase
- Context API
- Vanta.js

## Architecture Highlights

- Context API used to avoid prop drilling
- Reusable and modular React components
- Dynamic theme system
- Firebase used for storing and retrieving data
- Optimized rendering and component structure
- Scalable frontend architecture

## Installation

Clone the repository:

```bash
git clone https://github.com/Akerman048/Portfolio
```

Navigate to the project:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Firebase Configuration

Create a Firebase project and add your Firebase configuration:

```js
const firebaseConfig = {
  apiKey: "your_api_key",
  authDomain: "your_project.firebaseapp.com",
  projectId: "your_project_id",
  storageBucket: "your_project.appspot.com",
  messagingSenderId: "your_sender_id",
  appId: "your_app_id",
};
```
